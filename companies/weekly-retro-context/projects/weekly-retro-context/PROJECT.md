name: Weekly Retro Context
description: Gather weekly context from ClickUp and GitHub into deterministic JSON objects for retrospective use
slug: weekly-retro-context
owner: data-gatherer
---

This project is the company operating loop. Each weekly run gathers a strict
seven-day slice of ClickUp and GitHub activity, filters it down to evidence
that matters for retrospectives, and renders a stable JSON list.

The project stops after JSON generation and validation. It does not publish or
otherwise distribute the result.
